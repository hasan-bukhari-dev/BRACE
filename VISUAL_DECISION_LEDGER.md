# Visual choice audit

| Visual / route | User question | Actual source and encoding | Definition / exact alternative | Missing-state behavior / why visual |
|---|---|---|---|---|
| Wordmark suffix plate / global | Which task am I previewing or using? | Actual glyph bounds; suffix from focused/hovered button, committed caption separately underlined | Plain task captions, accessible button names and `aria-current` | Restores committed state on leave/Escape; five compact destinations with recognizable shared spelling. Not a scientific status visual. |
| RACE outcome strip | How do all frozen target outcomes divide? | Counts from active result classifications; segment width proportional to actual count | Adjacent exact count labels, complete gene table, selected-family denominator and target BH q<=0.05 definition | Zero selected has a literal zero-selection result. No decorative empty segments or manufactured support score. Faster family overview than reading 20 outcomes. |
| RACE source → freeze → target path | Did target outcomes select the genes? | Active source-screened, source-selected and target-testable counts; one-way order | TRACE contains source-only configuration, selected IDs and frozen hash | No back-arrow or target-to-source claim. Actual scientific selection boundary in one line. |
| Source/target rails / RACE and CE | Which dataset played which role? | Recorded cohort identities, sample/feature/group counts | Explicit source/target labels and processing disclosure; full hashes/counts in evidence | Unknown counts say unavailable. Paired alignment is useful for role comparison; no absolute-scale compatibility is implied. |
| FACE expression dots | What measurements support this gene's estimated association? | One actual value per included sample; negative/positive group, separate source/target y axes in normalized log-intensity units | Exact sample/value tables, within-study mean difference, Hedges' g, BH q and pointwise 95% interval; annotation source and exclusions | Absent feature/measurements produces text, not fake dots. Pointwise intervals are not selection-adjusted/simultaneous. Displays spread/outliers hidden by a single effect number. |
| ACE confusion matrix | Which true classes were mistaken for which predicted classes? | Actual saved integer counts, true rows / predicted columns, all evaluated records before confidence filtering | Per-class support and exact CSV/JSON; absent true classes explicit | No unlabeled accuracy. Counts rather than color carry the result; matrix makes error relationships visible. |
| ACE coverage rail and curve | What fraction remains and how often are those retained predictions correct? | Saved threshold points; x retained/all, y correct/retained, selected threshold marker | Exact numeric cutoff input, retained/withheld/correct/error counts, saved-curve CSV; equality retained | No probabilities or zero retained => explicitly unavailable/undefined. Curve omits undefined accuracy points; never interpolates a new evaluated cutoff or labels a post-hoc optimum. |
| Record class-score bars | Which scores accompanied this prediction? | Exact supplied class probabilities, one labeled bar per class | Exact JSON scores and true/predicted labels; not automatically calibrated correctness probability | No full vector => text. Relative class scores are easier to compare visually; no gene measurements invented. |
| CE PCA | How do target measurements project into the source-defined space? | Source fit/scaling/feature choice, actual PC1/PC2 coordinates, dimensionless axes and source explained variance | Source circles / target squares, exact coordinate/distance table and CSV | Unavailable projection says why. No fake zero counts. Reveals multivariate separation without claiming cause, model accuracy or harmonized absolute scales. |
| TRACE ordered chain | Which executed operations and artifacts produced this selection? | Actual step status/configuration, input/selection/model/metric hashes and artifact links | Expandable exact recorded data; absent operations labeled not performed | Fetch/integrity error exposes retry, preserves selection. Order supports audit, not theatrical pipeline animation. |
| Exported HTML | What was found, with what denominators and limits? | Actual saved RACE/validation/shift records; conclusion before identity/methods | Complete tables, warnings, configuration, links and SHA manifests | Failed integrity blocks export. Raw inputs excluded; matching originals required for reproduction. Document, not dashboard, supports independent review. |
