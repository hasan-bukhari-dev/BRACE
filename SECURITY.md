# Security reporting

BRACE is designed for a local single-user research session. Keep it bound to loopback; do not expose it as a public multi-user server. Uploaded code or arbitrary model binaries are not executed. Input limits and provenance checks are intentional controls.

Please report non-sensitive bugs through repository issues. For a suspected vulnerability involving private data, do not post raw uploads, exploit payloads containing personal information, credentials or patient identifiers. Use the repository owner's GitHub profile to arrange a private reporting channel before sharing sensitive details. No dedicated private security-reporting service is asserted here.

Signing/notarization availability, supported tested platforms and known limitations are reported per release. An unsigned preview is not an authenticated signed vendor installer. Verify published SHA-256 checksums, noting that a checksum is an integrity check rather than independent authorship authentication.
