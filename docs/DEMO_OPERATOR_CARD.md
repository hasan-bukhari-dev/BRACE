## Recovery

- Server unavailable: preserve completed runs; restart launcher, refresh/retry. Reselect files and recheck before another upload.
- Port conflict: choose an unused explicit loopback port; never silently show an unrelated service.
- Slow run: wait for actual completion. If needed switch explicitly to saved results; no fake progress.
- Export409: do not edit hashes to bypass. Use the unchanged included example as a labeled saved backup and investigate altered local evidence later.
- Projector/font issue: use rehearsed viewport/zoom and check actual hardware beforehand. Full-precision tables scroll horizontally.
- No internet: installed app/data do not need it. Fresh setup requires standard Python plus matching wheels; do not install on stage.
