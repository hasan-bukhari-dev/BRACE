BRACE 1.1.0-dev.1 - Integrated research workbench

Persistent datasets, reviewed preparation, versioned studies,
reproducible analysis, lineage, and scientific evidence export.

Windows: Download the windows-x64-setup.exe installer, or extract
the complete windows-x64-portable.zip and run BRACE.exe.
Python is bundled.

The Windows build workflow must pass the automated tests, native
executable checks, and installer install/uninstall verification
before this prerelease is published.

This is unsigned exploratory research software, not a validated
clinical device. Human accessibility testing, macOS/Linux
acceptance, and additional assay support remain incomplete.

See the accompanying implementation and verification records.
