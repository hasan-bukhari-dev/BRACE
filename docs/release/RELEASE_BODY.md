BRACE V6 is a local research preview: gene-association replication, saved-prediction evaluation, source-fitted distribution diagnostics and reproducible evidence export.

**Windows:** download the `windows-x64-setup.exe` installer, or extract the complete `windows-x64-portable.zip` and run `BRACE.exe`. Python is bundled. Keep the native controller open while using the browser workbench; Stop & close ends the local server. Generated runs live under `%LOCALAPPDATA%\BRACE`, outside the installation and retained on uninstall.

Other platform ZIPs, if attached, were built and checked on their own runners. Treat them as experimental until native GUI/device acceptance is complete. No macOS notarization or Windows signing is claimed for this initial preview. Use the accompanying checksums and actual verification receipts.

The curated public GSE42568 → GSE20711 example is included. Open saved evidence or review the exact inputs and compute again. Historical CancerShift records remain archived predictions; synthetic examples remain artificial. SPACE finds official GEO candidates and hashes bounded original downloads; scientific preparation and independence review remain necessary.

Scientific limits remain explicit: exploratory associations are not clinical validity, causality or automatic model-transfer evidence. Read the methods, data citations and original processing/independence warnings. Raw uploads are omitted from evidence exports by default.
