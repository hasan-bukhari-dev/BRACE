# Stage 07 — Scientific protocol and interpretation boundaries

## Inputs and eligibility

Stage 07 consumes the exact Stage 04 cohort contracts (feature rows × sample columns files, sample metadata, cohort manifest) and optionally the Stage 05 prediction-file + manifest format. It reuses `parse_cohort` and `evaluate_compatibility`; blocking conditions prevent shift analysis. It does not retrain a classifier. Retained prior-stage implementations remain in this package.

## Algorithms

1. Canonical shared feature IDs ordered lexicographically. No imputation, normalization, harmonization or adaptive correction applied.
2. Per feature: median shift = target median minus source median; source IQR = Q75–Q25; normalized median shift = median shift / source IQR only if IQR > 1e-12. Independently compute two-sided two-sample KS statistic, p-value, and BH adjustment across all shared genes. Gene ranking uses KS D, then absolute raw median shift, then gene ID. Different base distributions, imbalance, processing and sample correlation can change test validity.
3. Source PCA: compute source-only population variance. Keep up to 250 positive-variance genes ranked by source variance with gene-ID tie-breaking. Standardize with source-only means and standard deviations; fit sklearn PCA (full SVD, n_components=2) **only on source samples**; transform target without refitting. Projection variance ratios describe the source. For both cohorts compute Euclidean distance from the source PCA centroid divided per axis by source PC standard deviations. The source 95th percentile is a heuristic reference; it is NOT a calibrated uncertainty threshold. If <2 variable source genes or <3 source samples, omit PCA with an explicit reason.
4. Mode B: class support by cohort and per-class top 25 absolute median shifts, only when 3+ observations of the class exist in both cohorts. These summaries use target labels post-hoc and must not affect PCA or source-model training.
5. Optional prediction association: require exact, unique target sample ID coverage and identical reference labels in target sample metadata. Use validated Stage 05 prediction format. Sort target points by source-based PCA distance, split deterministically into four disjoint groups; summarize error counts and mean confidence, where genuine probabilities exist. These groups are descriptive and in-sample exploratory. No causality, conditional risk inference, source-to-target validation certification or new model fit is asserted.

## No forbidden label use

Unlabeled Mode C never computes class counts, class-conditioned shifts, error rates or outcome-conditioned visualizations. Source feature selection and PCA parameter fitting do not consult target expression data or labels; target expression is only transformed. In Mode B, target labels are consumed exclusively for post-hoc descriptive analysis of existing predictions and class-level distributions; they cannot be used to choose an adaptation method and then represent subsequent evaluation as untouched/blind.

## Report labeling

`run_report.html`, `shift_result.json`, `gene_shifts.csv`, `pca_samples.csv` are computed from input expression values. Optional `error_shift_samples.csv` and `error_shift_quartiles.csv` are computed from input predictions, not generated by the Stage 07 engine. `examples/stage07_historical_cancershift/` is explicitly historical manuscript-related comparison evidence with no new inference.

## Known limitations

Statistical distributions are unpaired; sample independence is assumed by KS-style p-values. Multiple related measurements or repeated patients can make p-values misleading. A method that makes cohort detection harder is not necessarily better for biological discrimination. External labels observed after tuning cannot be retroactively called blind. This code does not determine if an expression difference is disease-related, technical, or clinically important.
