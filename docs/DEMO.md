# BRACE V6 — five-minute operator path

Prepare dependencies before the event. Start the app and open the printed local address. All bundled demonstrations can run without GEO access after installation; SPACE requires internet for uncached discovery.

1. **Open saved public result.** Say: “This is recorded exploratory evidence from two public breast-tumor studies.” Point to the actual included cohort counts and the 20 source-frozen associations.
2. **Select one gene → FACE.** Explain the contrast and separate expression axes. Use **TRACE** to show source selection before target testing. Return to the same gene, then close the inspector.
3. **E → report → EMBRACE ZIP.** Show the feature legend, original file hashes and limitations. Do not call a hash proof of donor independence.
4. **B → Use another dataset / home → Run the public example again.** Review the verified files and scientific declarations, check, then compute. This is the actual rerun. The prepared example should reproduce 14 supported, 5 matching without support, 1 opposite estimated direction; do not promise that outcome for new data.
5. Optional: open **Historical research and software examples**. Historical predictions evaluate 680 saved records, not a rerun of CancerShift. The artificial baseline actually fits the supported pipeline; its accuracy is not biological evidence.
6. Optional online: **SPACE · Find public datasets**, search `GSE42568`, shortlist, verify available filenames. Explain that metadata and an original download are not automatically curated inputs.

Never call this clinical validation, causal proof, universal model training or a general RNA-seq preprocessing pipeline. No decorative animation represents statistical progress. If GEO is unavailable, use the verified local example rather than improvising metadata.
