# V5 product contract

Core job: identify the files a person has, guide them into one valid analysis, make the measured result legible, then inspect and export its evidence.

Visual direction: warm white and navy; interlocking blue/jade/iris/coral ribbons; polished colored tool tabs; generous chart surfaces with compact, meaningful labels. The supplied images are visual references. Their example genes, binary confusion matrix, cohort sizes and dates are not data sources.

Home: a useful public example and a guided own-data route. No insider knowledge or JSON editing required for common inputs. Expression intake: files → dataset descriptions → contrast → checks. Prediction intake: table → classes/scores → review → checks. Original file/feature limits and scientific eligibility stay enforced.

RACE: actual frozen gene outcome strip, readable table and linked paired effects. FACE: real box/dot measurements with separate axes. ACE: confidence/coverage as the central instrument, actual multiclass confusion counts, exact record inspection. CE: task-specific eligibility and interactive source-fitted projection/feature exploration. Evidence: actual readable report, recorded steps and verified downloads.

Preserve Python/FastAPI, engines, all existing datasets and historical evidence, APIs and exports. New read-only routes expose only verified built-in public inputs and the existing published report. Local pinned chart/CSV libraries; no network requirement at runtime. Every visible action has an outcome, keyboard access, failure recovery and an accessible name. Test real uploads, claims, plots, errors, responsive layouts, dark mode, zoom and regression suite. Human usability is never inferred from assertion counts.
