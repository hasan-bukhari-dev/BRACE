# Guided BRACE assistant

Ask BRACE is a floating, minimizable panel available across the workspace and inside tool dialogs. Click a suggested prompt to fill the editable message box, then click Send or press Enter. Shift+Enter inserts a line break. Typed keyword commands also work; unknown requests show guidance instead of fabricating an answer.

## Supported destinations

- BRACE home and data import/setup.
- RACE: the existing saved public ER replication analysis.
- ACE: the archived CancerShift prediction evaluation, your own prediction import, and source baseline setup.
- CE: the normal public-cohort comparison workflow. This computes a local comparison rather than claiming a saved result.
- FACE: gene measurements for the current RACE analysis, opening the bundled public analysis when needed.
- TRACE and EMBRACE: calculation records, methods, reports and exports for the current analysis.
- SPACE: the existing public dataset discovery dialog. Opening it does not automatically send a search.

The underlying data review, eligibility checks, analysis engines, visualizations and scientific interpretation remain authoritative. A running analysis blocks assistant task changes. The widget does not replace the normal controls.

## Demo boundary

This is a deterministic assistant prototype, not a live language model or retrieval-augmented generation implementation. The typing indicator is presentation feedback. Saved public analyses and archived predictions retain their existing provenance labels. Scientific results are loaded or computed through the same application functions as the standard interface. New user-data computations require the normal inputs and checks.

## Local preview

Run START_BRACE_WINDOWS.bat after dependency setup, then open the local address printed by the launcher. Refresh an already-open browser tab after updating the frontend files. Use the floating Ask BRACE button at the bottom right.

## Featured research stories

Three highlighted prompts provide a short presentation path: prepare the pinned breast cancer study pair for review; inspect the highest-score incorrect archived CancerShift record; and open the current analysis report and evidence exports. Preparation reuses the existing reviewed-public registration action, preserves unchecked scientific review declarations, and does not claim fresh normalization. The prediction story uses the normal ACE record inspector, sorted by the recorded maximum score.
