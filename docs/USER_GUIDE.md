# User documentation

Start with the [two-page quick start](QUICK_START.pdf) or its [text version](QUICK_START.md).

The authoritative [illustrated researcher manual](USER_MANUAL.pdf) covers installation, the connected data workflow, RACE, FACE, TRACE, ACE evaluation and baseline replay, CE, evidence, recovery and backups. Its [editable source](manual/USER_MANUAL.md) and [authentic screenshots](manual/screenshots/) are versioned alongside the application. In BRACE, choose the question-mark help button, then User manual · PDF.

Use [Input formats](DATA_GUIDE.md) for exact input contracts, [Reproduction and storage](REPRODUCIBILITY.md) for hashes and restore boundaries, and [Methods and limitations](SCIENTIFIC_PROTOCOL_1_0.md) for the scientific scope. [New-data instructions](NEW_DATA.md) provide a compact text reference.

E and EMBRACE are one evidence destination. SPACE belongs to acquisition; FACE and TRACE inspect the selected analysis. Prepared measurements remain reusable, while each saved run retains its exact input and parameter identities.
