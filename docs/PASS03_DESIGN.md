# Frontend foundation

Core job: choose two cohorts or prediction records, check task-specific eligibility, run locally and retain inspectable evidence. New users get two initial actions and plain task labels; experienced users retain explicit manifest import and exact numerical exports.

Identity: calm, precise, approachable. Native Segoe UI/system fonts; 15px body; 8px spacing rhythm; navy #0B1924, surface #142B38, teal #79CAC0, amber caution and visible amber focus. No external fonts, CDN scripts, framework, decorative chart, fabricated progress or new runtime package. Actual results alone create numerical summaries. Press feedback lasts 120–140ms and is removed under reduced motion.

Before: Study / Validation / Cohort shift / Evidence; archived evidence selected on startup; an always-visible introduction, historical and synthetic feature cards and a flat upload form. After: Study / RACE · Genes / ACE · Models / Evidence; empty initial study; real public example or own-data entry; history and synthetic examples behind an explicit disclosure; cohort shift inside ACE; one contextual record inspector.

Modules: `app.js` initializes and composes views; `js/state.js` owns active run/navigation/selection and session restoration; `api.js` translates server responses; `study.js` handles task-specific file entry and preflight; `ui.js` formats/escapes text; `inspector.js` owns native dialog focus; `legacy-results.js` preserves model, shift and archived-result rendering. No scientific computation was moved into JavaScript.

Input → check → review actual previews/warnings → enable the selected analysis → run → results/evidence. Modifying inputs invalidates the check. Prediction-only users see two file inputs. Cohort users see source/target expression, metadata and explicit manifests. RACE additionally requires explicit group names, biological definitions and equivalence acknowledgement. The interface never invents assay or independence declarations. No manifest-generation wizard was added; advanced import is the supported route in this pass.

Running jobs disable data changes while navigation remains available. The last successful run survives invalid input or a failed request. New model jobs open model results; ordinary navigation preserves the chosen model/shift subview. Session storage keeps run ID, view, task, filters, selections and inspector identity, not expression values or uploaded File objects. Completed runs are fetched again from their existing server record. After refresh, inputs must be selected and checked again. Interrupted requests are not resubmitted automatically. The durable evidence remains in local run folders.

The approved public example is a hash-checked saved computation, explicitly labeled. It is neither a synthetic stand-in nor silent fresh execution. Public results are read-only and fail closed if pinned files are changed. Fresh RACE is available through actual uploads. Generic uploads retain the user-supplied evidence category even when users name a GEO accession.

Accessibility: semantic buttons/labels, skip link, main landmark, live status, aria-current navigation, native dialog plus explicit Tab cycling, Escape dismissal and opener focus restoration, visible focus, reduced motion and responsive reflow. Narrow gene tables scroll horizontally with a visible hint rather than splitting identifiers. Uncertainty and limitations stay visible or directly expandable. This is not a full WCAG/screen-reader certification.

Verification: `python -m pytest -q`; `python tests/browser_pass03.py --url http://127.0.0.1:8765`. Browser tests require installed Chrome and optional development package `playwright==1.64.1` (Apache-2.0, confirmed from installed metadata). No Playwright dependency is required to run BRACE. Test-only `browser_host.py` permits testing on 8766 when the production port is occupied; it normalizes only its local test origin before calling the unchanged production origin policy. Launch it with `python -m uvicorn browser_host:app --app-dir tests --host 127.0.0.1 --port 8766`. Production startup never imports that adapter. The before screenshot came from the untouched Pass 2 server on 8767.

Full RACE molecular plots/inspection belong to later work. This pass offers a real summary table, filtering, sorting, selection, methods and exports; existing sample and shift-feature inspectors remain functional. Human usability, screen-reader software, other browser engines, projector behavior and clean-device setup remain unverified.
