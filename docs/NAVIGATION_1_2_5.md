# BRACE 1.2.5 navigation supplement

The application header now contains a larger BRACE logo and the existing search, help and theme controls. Below it, the five B R A C E destinations are centered in a larger navigation module on the workbench. Analysis pages use a compact version.

Hover over or focus a destination to read its full name. Click it, or press Enter or Space, to navigate. Preview does not change the active analysis. The underline marks the active page; the focus outline marks the keyboard position. Left/Right arrows move focus, Home/End move to the first/last destination, and Escape restores the selected tool's description. Reduced-motion settings remove the rectangle transition.

| Letter | Tool | Full name |
|---|---|---|
| B | BRACE | Biological Reliability Assessment across Cohorts and Experiments |
| R | RACE | Replication Assessment of Cohort Effects |
| A | ACE | Algorithmic Classifier Evaluation |
| C | CE | Cohort Evaluation |
| E | EMBRACE | Evidence Management, Bundling, Reproducibility, Audit & Controlled Exports |

The question controls now show RACE, ACE and CE instead of single-letter labels. Their behavior is unchanged. Data preparation, scientific declarations, eligibility checks and result inspection remain in the existing workflows.

The floating Ask BRACE control opens the guided demo assistant. Suggested requests fill an editable message box; Send executes the recognized command. It is not live AI retrieval. Unrecognized requests show guidance. Hover reveals the launcher label; moving away from an open panel collapses it after a short delay. Draft text is preserved, and the panel remains open during keyboard interaction or an active request. Touch users can use the launcher and minimize control directly.

The existing illustrated manual documents the previous application shell. Its scientific workflow guidance remains useful, but its navigation screenshots have not been regenerated for 1.2.5. Use this supplement for the new shell.
