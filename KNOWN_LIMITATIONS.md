# Known limitations — BRACE 1.0 Hatchathon

- Research use only. No diagnostic, causal, biomarker certification, regulatory or prospective clinical claim.
- Public ER cohort processing and ascertainment differ; source donor identities are unavailable, cross-study donor independence is incompletely authenticated, and unadjusted biological/technical confounding remains. Separate cohort acquisition is evidence for exploratory design, not proof of independent patients.
- RACE accepts a narrow unpaired processed-microarray design. No raw sequencing/CEL processing, covariate/paired/survival inference, generalRNA-seq count testing, single-cell/spatial/epigenomics pipelines or automatic harmonization. Effects remain within-cohort normalized log-intensity differences, not casually relabeled fold changes.
- Source-only variance/probe preparation restricts the gene universe. Source-selected intervals are pointwise, not selection-adjusted/simultaneous. BH assumptions and patient/study dependence remain.
- Mode B is the preserved normal/tumor binary logistic baseline. Public ER direct-scale comparison and model transfer are not approved. Uploaded executable models are rejected.
- Historical CancerShift predictions/research predate the event. Original trained weights/raw training expression are unavailable; fresh original-classifier inference is not claimed. CPTAC lacks true prostate support and has study/class confounding. Row-level intervals do not solve clustering.
- Confidence is a supplied/model score, not automatically calibrated or clinical probability. A more restrictive cutoff still retains a real confident error. Post-hoc slider exploration does not create a prospectively validated policy.
- Shift is descriptive. It neither establishes performance deterioration without labeled outcomes nor proves an error's cause. No fabricated accuracy appears in Mode C.
- Private input files are retained locally with run records, but excluded from evidenceZIP by default. Derived identifiers/scores can still be sensitive. File hashes are not consent, data-license permission, authenticated acquisition or protection against replacement of every local receipt.
- Full-precision tables/inspectors require local scrolling on smaller displays. Browser checks and sampled contrast/keyboard/reduced-motion behavior are not comprehensive accessibility or screen-reader certification.
- The source release is not a self-contained Windows executable. A standard compatible Python must be installed separately. The optional wheelhouse targets CPython3.11x64, not arbitrary Python/OS combinations. This machine was not a clean reinstalled Windows or the actual event laptop.
- Default port 8765 is retained, but it was unavailable in this host environment. Final browser/lifecycle checks used the explicit8766 fallback. Do not stop unrelated services to make a port available.
- Ten repeated automated demos are developer software checks, not ten narrated human demonstrations. Physical Wi-Fi-off, projector/external display, unfamiliar-user outcomes, spoken pitch timing and official reuse/AI/team eligibility remain pending.
- Heavy concurrency can exceed the old browser harness's five-second upload deadline. Single-workflow acceptance passes; no multiuser/service latency guarantee.

No known release-blocking numerical/scientific defect remains in the exercised scope. Full event acceptance is **conditional** on hardware rehearsal, human presentation and eligibility confirmation. Review `PASS_07_FINAL_ACCEPTANCE.md` for exact measured statuses.

## V6 current additions and unresolved acceptance
SPACE performs bounded official GEO discovery, actual matrix listing and original gzip acquisition; it does not automatically prepare cohorts, authenticate independent patients or approve a study pair. Compressed acquisition size and prepared API size are independent gates. Generic report branding remains domain-neutral; biological reports use the full canonical BRACE expansion. All original scientific limitations apply. Fine-grained live algorithm stages/cancellation are not implemented; only real request start/end/error is displayed. Unfamiliar-user, screen-reader, physical touch/projector and fresh Python 3.13 target-install acceptance remain NOT RUN. See docs/v6/HUMAN_ACCEPTANCE_PENDING.md.
